# AI 建站指南

给新手的四页静态教程：首页、生成、修改、上线。生成和修改页会根据读者的选择显示对应内容；生成页可填写需求并实时预览、复制提示词。修改页还用五张自绘图说明 Tooltip、Toast、Alert、Modal 和 Popconfirm。词典、Tips 和上线清单均在浏览器内运行。

## 本地预览

在仓库根目录运行 `python -m http.server 5188 --bind 127.0.0.1`，打开 `http://127.0.0.1:5188/`。

网站无需安装依赖或执行构建命令。四个 HTML 文件和 `assets/` 目录就是发布文件；GitHub Pages 从 `main` 分支根目录提供页面。
