# AI 建站指南

给新手的四页静态教程：首页、生成、修改、上线。生成和修改页会根据读者的选择显示对应内容；生成页可填写需求并复制提示词。修改页包含五种界面提示、电脑与手机布局对照，以及六种滚动动效示例。首页首屏使用缓慢漂移的蓝灰色渐变，并尊重系统“减少动态效果”设置。

## 本地预览

在仓库根目录运行 `python -m http.server 5188 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:5188/`。

## 发布

网站无需构建。GitHub Pages 从 `main` 分支根目录提供四个 HTML 页面和 `assets/` 资源。
