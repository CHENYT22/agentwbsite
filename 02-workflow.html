第 02 章 · Beginner's Guide

做网站的流程和怎么开口

五步流程看清全貌；三要素需求法让你一句话就能讲清楚要什么。

预估阅读 3 分钟 难度：新手友好
五步流程

从想法到上线，只走这五步。

01

想清楚要什么

谁会看？解决什么问题？大概几页？你负责。

02

讲给 Agent 听

用「目标 + 受众 + 风格」三句话描述，Agent 负责拆解和实现。

03

Agent 生成页面

通常一轮给出完整 HTML + CSS，你负责复制到本地文件。

04

本地预览改稿

浏览器打开看效果，不满意就再回去讲一段「这个改大点、那里换个颜色」。

05

部署上线

推到 GitHub → 开启 Pages → 拿到一个能发给别人的网址。

讲清楚需求：三要素

不需要写六要素模板——记住下面三句就够用：

A

目标

这个页面是干嘛的。例：「咖啡店的课程报名落地页」。

B

受众

谁会来看。例：「25–35 岁想学手冲的城市白领」。

C

风格

像什么。例：「极简黑白，大字标题，像 Apple 官网」。或贴一个参考链接。

把这三句粘给 Agent，就已经超过 80% 的新手提示词了。
