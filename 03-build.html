03 / 上线

把网站发布出去。

01

先认识两个词

GITHUB

存放网站文件

GITHUB PAGES

把文件发布成网址

02

上线五步

进度 0 / 5

查看操作

请 Agent 整理静态网站文件。确认入口文件为 index.html，图片和样式文件也在发布文件夹内。

查看操作

登录 GitHub，创建一个新仓库。使用免费方案时，将仓库设为 Public。

查看操作

把发布文件夹内的所有文件上传到仓库根目录并提交。打开仓库时应能直接看到 index.html。

查看操作

打开仓库的 Settings → Pages。在 Build and deployment 中将 Source 设为 Deploy from a branch，选择存放文件的分支和 /(root)，然后点击 Save。

查看操作

部署完成后，打开 Pages 提供的网址，检查图片、链接和手机端显示。确认正常后再分享。

界面选项可能更新。操作时可对照 GitHub Pages 官方说明 ↗。

FINAL CHECK

检查完成，
再分享网址。

确认图片、链接和手机端正常。
