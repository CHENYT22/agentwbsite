第 04 章 · Beginner's Guide

不懂设计，也能让它高级

色彩、字体、间距、圆角——四个变量决定了页面是「像样」还是「廉价」。新手也能掌握。

预估阅读 10 分钟 难度：新手友好
本章要点

页面的「高级感」不是天赋，是四个可量化变量的结果：颜色、字体、间距、圆角与阴影。你不需要会设计，只需要把这四个变量的规则讲给 Agent。

一、为什么先说设计系统，而不是直接堆样式

没有规矩的页面会呈现一种典型病征：每看一个区块，都像是另一个人做的。标题有时大有时小，圆角一会儿 8 一会儿 24，灰色用了五种都没统一。单看每一块都还行，合起来就是廉价。

设计系统就是提前定好这些规矩，然后让 Agent 全程遵守。你只需要在开头说一次，后面每加一个区块，它自己会对齐。

二、变量一：颜色——只用一个强调色

新手最安全的配色方案不是「找漂亮的配色」，而是黑白灰 + 一个强调色。这一套几乎不会出错，而且天然显得贵。

角色 建议色值 用在哪
页面底色#FBFBF9（比纯白暖一点点）整个页面背景
卡片底色#FFFFFF需要浮起来的块
次级填充#F4F3EF代码块底、标签底
主文字#0C0C0B（不用纯黑 #000）标题
正文文字#46453F段落
辅助文字#78776F说明、时间、注释
分隔线#E7E6E0（发丝级）区块之间的横线
强调色（可选）任选一个，全站只用它链接、按钮、重点标记

配色比例遵循 60 : 30 : 10：60% 是底色和留白，30% 是文字与结构线，10% 留给强调色。强调色超过 10%，页面立刻变吵。

直接可用的说法

「整站只用黑白灰和一个强调色。底色用 #FBFBF9，正文 #46453F，辅助文字 #78776F，分隔线 #E7E6E0。不要出现第二种彩色。」

三、变量二：字体——拉开层级，而不是加粗

绝大多数「不好看」的页面，问题出在标题和正文的差距太小。想做出档次，让层级差距夸张一点：

  • 首屏标题：正文的 2.5–3 倍，字重 600，字间距收紧（-0.03em）；
  • 区块标题：正文的 1.6–2 倍，字重 600；
  • 正文：16px 起，行高 1.75–1.85（中文比英文需要更松）；
  • 小标签 / 注释：11–13px，可用等宽字体并大写，显得克制专业。

关于中文字体的一个实用建议：直接用系统字体栈，不要为了「好看」去引一个中文字体 CDN——中文字体文件动辄几 MB，加载慢到你怀疑人生。

字体栈（可直接抄）
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI",
             "PingFang SC", "Microsoft YaHei", sans-serif;

/* 结构感更强时，小标签用等宽字体 */
font-family: ui-monospace, "SF Mono", Consolas, monospace;

另外记住一个细节：字重不要滥用。一页里出现三种以上字重（400 / 500 / 600 / 700 混着来），会显得毛躁。标题 600、正文 400，通常就够了。

四、变量三：间距——留白要敢给，且要成体系

「留白多」是高级感最便宜的来源。新手最怕页面空，习惯把所有东西挤在首屏，结果就是没有呼吸感。

用一个 8 的倍数做间距阶：8 / 16 / 24 / 32 / 48 / 64 / 96 / 128 px。然后区分两个层级：

层级 间距范围 说明
元素内部8–16px图标与文字、标签与数字
卡片内边距24–32px太小会显得拥挤
同组元素之间16–24px卡片间距、列表项间距
不同区块之间64–128px关键——这里给不够，页面就没有段落感

判断是否给够的土办法：把页面缩小到 30% 看一眼，如果各区块糊成一片，说明区块间距不够。

五、变量四：圆角与阴影——要么统一，要么不用

圆角是最容易暴露问题的变量。8px、12px、24px、99px 混用在同一个页面里，看起来就像从三个网站各抄了一块。

  • 定一套圆角，通常三级即可：小元素 8–10px、卡片 14–16px、大容器 20–24px；
  • 按钮用胶囊形（999px）或与卡片同圆角，二选一，不要两套并存；
  • 阴影越淡越贵。不要用 box-shadow: 0 0 20px rgba(0,0,0,.3) 这种「黑乎乎一圈」，改成：
阴影三级（可直接抄）
/* 1 级：默认态，几乎看不见，只是让卡片不贴地 */
box-shadow: 0 1px 2px rgba(12,12,11,.04);

/* 2 级：悬停时轻微抬起 */
box-shadow: 0 12px 32px -12px rgba(12,12,11,.14);

/* 3 级：弹层、抽屉 */
box-shadow: 0 24px 60px -20px rgba(12,12,11,.18);

如果拿不准，宁可不用阴影，只用一条 1px 的浅灰边框。极简风格里，发丝边框比阴影高级得多——参考站能成立，很大程度就是靠这个。

六、把四个变量打包给 Agent

把下面这段作为「设计规范」在对话开头交给 Agent，之后每次让它加区块，都提醒一句「遵循前面的设计规范」。

设计规范（直接复制给 Agent）
:root {
  /* 颜色：黑白灰 + 零个彩色 */
  --paper: #FBFBF9;  --surface: #FFFFFF;  --surface-2: #F4F3EF;
  --ink: #0C0C0B;    --ink-2: #46453F;    --ink-3: #78776F;
  --line: #E7E6E0;

  /* 间距：8 的倍数 */
  --s1: 8px; --s2: 16px; --s3: 24px; --s4: 32px;
  --s5: 48px; --s6: 64px; --s7: 96px; --s8: 128px;

  /* 圆角：三级 */
  --r-s: 10px; --r-m: 16px; --r-l: 24px;

  /* 字体 */
  --font-sans: -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif;
  --font-mono: ui-monospace, Consolas, monospace;
}

要求：
1. 所有颜色、间距、圆角只能引用上面的变量，不要新造色值；
2. 标题字重 600，正文字重 400，不出现第三种字重；
3. 区块之间垂直间距不小于 96px；
4. 不用大面积阴影，需要边界时用 1px 的 --line 边框；
5. 字号：首屏标题 clamp(2.5rem, 6vw, 4.5rem)，正文 16px，行高 1.8。

七、三个「立刻变好看」的急救手法

手法一：把首屏标题放大 1.5 倍

90% 的页面标题都太小。放大之后同时收紧字间距、放宽行高，气势立刻就出来了。

手法二：把所有区块间距翻倍

32px 改 64px，64px 改 128px。页面会瞬间从「文档」变成「作品」。

手法三：删掉所有彩色

只留黑白灰，把彩色收到最多一个强调色。这一步对廉价感的治愈率极高。

八、廉价感的六个来源自查表

症状 病因 处方
颜色很花但说不清哪里怪彩色超过两种，没有主次回到黑白灰 + 一个强调色
标题不醒目标题与正文字号差小于 2 倍放大标题，收紧字间距
挤、闷区块间距小于 48px间距翻倍，留白要敢给
像好几个网站拼的圆角、字重、灰阶不统一用变量统一，禁止新造色值
糊大面积黑阴影 + 深色边框改发丝线或极淡阴影
乱对齐方式混用（左中右混排）全站统一左对齐，居中只用于首屏标语
