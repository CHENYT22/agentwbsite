Three Words

先懂三个词

聊工具之前，先把这三个词弄清楚。点开看一句话解释。

一个能听懂你说话、并代替你动手干活的 AI 员工。

给 Agent 装上的某项专业技能，比如「读 PDF」「写表格」。

让 Agent 能直接连上外部 App 的钥匙，比如直接收发邮件。

Tips · 怎么让 Agent 装上 Skill 和插件

01直接说需求就行：「帮我装一个能读 PDF 的技能」，它会告诉你在哪点。
02多数工具在「设置 → 技能 / 插件市场」里搜名字，一键就能装。
03装完通常先要权限（读文件、发邮件），不同意就不给。
Five Types

五类工具，分工明确

选错类别，再贵的产品也做不出你想要的东西。

对话型 Agent
代表ChatGPT、Claude、文心一言
适合不会写代码、想完全可控的人
缺点输出要自己复制粘贴到本地
编程型 Agent
代表Cursor、Claude Code、Codex、Trae、Cline
适合已会装客户端、追求效率的人
缺点需要安装客户端，门槛最高
建站生成型
代表v0、Lovable、Bolt
适合想一句话最快出图的人
缺点样式固定、二次改动受限
设计型 Agent
代表MasterGo 莫高、Figma Make
适合有设计稿、想高度还原的人
缺点没有设计稿就没有用武之地
通用型 Agent本教程用的就是它
代表WorkBuddy、Manus、Devin
适合新手、懒得选的人
缺点覆盖广，单项深度略逊专精工具
How To Choose

新手怎么选

和首页「三秒选工具」是同一套结论，选哪种都不会错。

🌱
我完全不会代码

选通用型 Agent（WorkBuddy）——网页里聊着就把事办了，不用安装。

⚡
我要最快出图

选建站生成型（v0 / Lovable / Bolt）——一句话生成可发布站点。

🎨
我有设计稿

选设计型 Agent（MasterGo 莫高 / Figma Make）——从稿子直接出页面。

🧰
我想要万能帮手

选通用型 Agent（WorkBuddy / Manus / Devin）——覆盖前几类的大部分场景。

⚠️ 新手提醒：别一上来就装编程型客户端——先用网页版工具跑通全流程，再考虑升级。
