先懂三个词

聊工具之前，先把三个词弄清楚。

核心结论

五类工具，分工明确。

选错类别，再贵的产品也做不出你想要的东西。先记住这张表，再挑工具。

01

对话型 Agent

聊天窗口里完成「想—说—改」全过程。代表：ChatGPT、Claude、文心一言。适合不会写代码的人，缺点是输出要自己复制粘贴到本地。

02

编程型 Agent

读你的代码库，直接改文件并提交。代表：Cursor、Claude Code、Codex、Trae、Cline。需要安装客户端但效率最高。

05

通用型 Agent

把对话、工具调用、浏览器、Skills 插件整合在一起的「什么都干」型。代表：WorkBuddy、Manus、Devin。新手选这一类通常就够了，它能覆盖前四类的大部分场景。本教程就是在 WorkBuddy 里写的。

03

建站生成型

一句描述直接生成可发布站点。代表：v0、Lovable、Bolt。一键出图最快，但样式固定、二次改动受限。

04

设计型 Agent

从设计稿或截图出页面。代表：MasterGo 莫高、Figma Make。已有设计稿、或想高度还原参考站时用。

新手怎么选

零基础想要「聊着聊着就出页面」：选 03（建站生成型）。想完全可控、能逐字改：选 01（对话型）+ 自己保存文件。已经会装客户端、追求效率：选 02（编程型）。有现成设计稿：选 04。懒得选 / 想要一个万能帮手：选 05（通用型 Agent，比如 WorkBuddy）。

本教程用的是 通用型 Agent（WorkBuddy）——最普适的一种。它把对话、写代码、调用工具、读文件、打开浏览器这些事一次性搞定，省去了「选哪个类型」的纠结。掌握了再换别的很容易。
