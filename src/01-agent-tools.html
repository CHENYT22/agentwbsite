本章要点

Agent 工具分四类：对话型、编程型、建站生成型、设计型。它们的差别不在「谁更聪明」，而在「谁被允许动手」——能不能读写文件、能不能跑命令、能不能直接发布。搞清楚这一点，选型就不会错。

一、先分清：Agent 和聊天机器人有什么不同

你可能已经在用 AI 聊天工具了。但「会聊天」和「会干活」是两件不同的事。

聊天机器人只做一件事：你问，它答。它给你一段文字、一段代码，然后停在那里。剩下的事情——把代码存成文件、起一个本地服务器、检查页面有没有跑起来——都得你自己来。

Agent（智能体）在「回答」之外，还被授予了动手的权限。它能：

  • 读写文件：直接在磁盘上创建 index.html、style.css，而不是把代码贴在聊天框里等你复制。
  • 执行命令：自己运行代码、起本地预览服务、看报错、再自己改。
  • 多步骤完成任务：你给一个目标，它自己拆成若干步，边做边检查，做完再汇报。
  • 调用外部服务：连接部署平台、设计工具、数据源，把「做完」推进到「上线」。

所以本教程里说的「用 Agent 做网站」，真实含义是：你负责说清楚要什么和判断好不好，Agent 负责把文件写出来、跑起来、发上去。

二、四类工具的完整地图

市面上的工具数量很多，但按「能力边界」拆开，其实只有四类：

类别 代表工具 它最擅长 新手典型场景
对话型通用 Agent ChatGPT、Claude、Gemini、豆包、腾讯元宝、Kimi 理清思路、写文案、生成单页代码 想不清楚要做什么时，先聊一轮
编程型 Agent Cursor、Claude Code、GitHub Copilot、Windsurf、Trae 在真实项目里建多个文件、跑命令、调试 要把网站做完整并反复修改
建站生成型 Agent v0、Bolt.new、Lovable、Replit Agent、秒哒、云指建站 对话直出可视化页面，自带预览与一键发布 最快看到一个能打开的网站
设计型 Agent Canva 可画、MasterGo 莫高、Figma、创客贴、美图设计室 配色排版、出图、把设计稿转成代码 页面内容有了但「不好看」

注：以上工具的免费额度、付费方式与能力更新非常快，本章只讲定位与适用场景，具体价格与功能请以各产品官网为准。

1. 对话型通用 Agent：用来想清楚，不是用来收尾

这类工具最普及，也最容易被误用。它们的强项是理解与梳理：帮你把模糊的想法变成一句能执行的需求，帮你写页面上的文案，帮你判断两个方案哪个更合适。

部分产品已经可以生成可在浏览器里直接预览的网页代码（例如产物预览类功能），做「单页小东西」完全够用。但当项目变成多个文件、要加交互、要反复迭代时，你会明显感觉到聊天框装不下这个工作量。

一句话定位

把它当策划和文案用，效果最好；把它当唯一的开发工具，很快就会难受。

2. 编程型 Agent：真正能把网站「做出来」的一类

这类工具运行在你的编辑器或终端里，被授予了读写文件和执行命令的权限。它可以直接：

  • 创建 index.html、style.css、assets/ 等一整套文件结构；
  • 自己运行本地预览，发现报错后自己修；
  • 一次修改影响五个文件时，同步改掉，不用你来回粘贴。

对新手而言，这类工具的价值是：你不需要看得懂所有代码，但你可以要求它解释、要求它改、要求它重做。它把「写代码」变成了「提要求 + 验收」。

代价是它需要一点环境概念——本地要有一个文件夹、要知道怎么打开预览。这几步在第 6 章会手把手过一遍。

3. 建站生成型 Agent：最快拿到一个能打开的网址

这类平台把「生成代码 + 预览 + 部署」打包在一个网页里。你描述需求，它给你一个实时预览窗口，满意了直接点发布，拿到一个公开链接。整个流程不需要装任何软件，最适合零基础的第一站。

适合的场景：落地页、个人主页、活动页、产品介绍页。它们的默认审美通常已经在及格线以上，模板化程度高——这也意味着深度定制会比较受限。

新手建议

如果你只想尽快看到成果建立信心，从这类工具开始；如果你想把网站当成长期资产持续改，再转向前两类。

4. 设计型 Agent：解决「不好看」这个具体问题

页面结构对了、内容齐了，但看上去就是廉价——这是新手最常卡住的一关。这类工具的职责是把设计水准补齐：

  • 素材与配图：海报、封面、图标、社媒配图，一句话生成；
  • 排版与配色：基于成熟模板调整版式，避免自己从零调；
  • 设计转代码（D2C）：把设计稿直接转成前端代码，减少「设计很好看、实现很崩坏」的落差。

如果你不想引入额外工具，也可以只用第 4 章的设计系统四变量 + 提示词约束，让编程型 Agent 直接产出及格线以上的视觉。

三、用三个问题选出你的工具

问题一：我今天就想发给别人看，还是慢慢打磨？

想立刻发出去 → 建站生成型。愿意花两三天打磨 → 编程型 Agent。

问题二：我连要做什么都还没想清楚？

那就先用对话型 Agent 聊一轮。把「目标、受众、包含哪些内容」聊出来，再换工具动手。这一步花 20 分钟，能省掉后面两小时的返工。

问题三：做完之后，是不是还要改很多次？

会反复改 → 一定要选能修改源文件、能长期维护的方式。纯拖拽式工具在第三次改版时开始让人难受。

四、给新手的推荐组合

方案 A · 零基础最快路径

建站生成型 + 设计型

对话直出页面并一键发布，配图与视觉交给设计型工具。全程不需要装软件，一两个小时内能拿到公开链接。

代价：深度定制受限，后期改版依赖平台。

方案 B · 长期可用路径（推荐）

对话型 + 编程型 Agent

先用对话型理清需求，再用编程型 Agent 在本地建项目、跑预览、部署上线。文件在你手里，随时能改、能搬、能扩展。

代价：前 20 分钟需要熟悉「文件夹 + 本地预览」这两个概念。

本教程剩下的章节按 方案 B 展开，但在每一步都会说明「如果你想用方案 A，对应该怎么操作」。

五、先认识这几个词，后面不卡壳

术语 说白了是什么意思
提示词（Prompt） 你对 Agent 说的那段话。它的质量直接决定产出质量。
本地预览 在你自己的电脑上先把网站打开看效果，只有你能看到。
静态网站 没有后端数据库的网站，由 HTML/CSS/JS 文件组成，免费托管即可上线。
部署 / 上线 把这些文件放到公网服务器上，别人就能通过网址访问。
响应式 同一个页面在手机和电脑上都能正常显示、不串行不溢出。
设计系统 一套统一的颜色、字号、间距规则，用来保证整站看起来是一家人。
