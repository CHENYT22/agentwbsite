Agent

一个能听懂你说话、并代替你动手干活的 AI 员工。

🎓
Skill

给 Agent 装上的某项专业技能，比如「读 PDF」「写表格」。

🔌
插件

让 Agent 能直接连上外部 App 的钥匙，比如直接收发邮件。

Skill 怎么装
01直接说需求就行：「帮我装一个能读 PDF 的技能」，它会告诉你在哪点。
02多数工具在「设置 → 技能 / 插件市场」里搜名字，一键就能装。
03装完通常先要权限（读文件、发邮件），不同意就不给。

通用型 Agent本教程用的就是它
代表WorkBuddy、Trae、Manus、Devin
适合完全不会代码的新手、懒得折腾的人
优点网页登录就能用，聊天、写代码、存文件一条龙
缺点覆盖广，单项深度略逊专精工具
更轻的代替：纯对话型（ChatGPT / Claude / 文心一言）能聊但代码要自己复制粘贴，新手不推荐。
编程型 Agent
代表Codex、Trae、Cursor、Claude Code、Cline
适合已熟知基础操作、追求效率的人
优点改动、调试都在自己电脑里完成，效率最高
缺点需要安装客户端，门槛最高

⚠️ 新手提醒：别一上来就装编程型客户端——先用网页版工具跑通全流程，再考虑升级。
