Pick Your Agent

工具选择

你更像哪一种？点一下，下面会亮起推荐。

通用型 Agent本教程用的就是它
代表WorkBuddy、TreaWork 等
适合完全不会代码的新手、懒得折腾的人
优点网页登录就能用，聊天、写代码、存文件一条龙
缺点覆盖广，单项深度略逊专精工具
更轻的代替：纯对话型（ChatGPT / Claude / 文心一言）能聊但代码要自己复制粘贴，新手不推荐。
编程型 Agent
代表Codex、TraeCode、Cursor、Claude Code 等
适合已熟知基础操作、追求效率的人
优点改动、调试都在自己电脑里完成，效率最高
缺点需要安装客户端，门槛最高

⚠️ 新手提醒：别一上来就装编程型客户端——先用网页版工具跑通全流程，再考虑升级。
Your Need

需求：两条路挑一条

不管走哪条，最后都是把「目标、受众、风格」说给 Agent。

A · 已有详细需求和框架
把详细需求与框架整理好，直接给 Agent

用提示词三要素卡把目标、受众、风格理成需求框架，直接发给 Agent。

B · 没有具体想法
① 像聊天一样问它
我想做一个 xxxx 网站，我可以怎样开始？
② 用三要素 + 模板卡先开始

先看提示词三要素卡理清思路，再跳转默认模板——复制模板卡，先开始尝试。

Three Elements

提示词三要素卡

不用背模板，记住 A、B、C 三句就够用。

A / GOAL
目标

这个页面是干嘛的。

例：「咖啡店的课程报名落地页」

B / AUDIENCE
受众

谁会来看。

例：「25–35 岁想学手冲的城市白领」

C / STYLE
风格

像什么，或直接贴一个参考链接。

例：「极简黑白、大字标题，像 Apple 官网」

Prompt Template

提示词模板卡（可复制）

复制模板卡，先开始尝试——把方括号换成你的，粘给任何 Agent。

PROMPT · 四句话
我想做一个[目标：咖啡课程报名落地页]。 受众是[受众：25–35 岁想学手冲的城市白领]。 风格[风格：极简黑白、大字标题、留白多，像 Apple 官网]。 结构：顶部一句话主张 + 三个课程亮点 + 底部报名表单。

把这四句粘给 Agent，就已经超过 80% 的新手提示词了。
