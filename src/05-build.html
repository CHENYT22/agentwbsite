本章要点

跟着做一遍完整的六步。案例是「周末手冲咖啡课」的单页介绍站——内容真实、结构典型，做完你就掌握了八九成的场景。

准备：你需要知道的两个概念

只有一个前置知识：网站就是一堆文件。一个最简单的网站通常长这样：

文件 作用
index.html页面本体。文件名固定，因为服务器默认打开它
assets/style.css样式表。也可以直接写在 HTML 里（新手推荐）
assets/放图片、图标、字体等素材的文件夹

你要做的第一件事，是在电脑上新建一个空文件夹，比如 my-site，然后用 Agent 打开这个文件夹。后面所有文件都会生成在这里，不会弄乱你的桌面。

给用方案 A 的同学

如果你用的是建站生成型平台，跳过「建文件夹」这一步——平台已经替你准备好了项目空间，直接从下面第 1 步的提示词开始。

提第一轮需求：只要结构，不要样式

先把六要素写全，并且明确要求「先不要写样式」。这一步的产出是一份清楚的内容骨架。

第 1 轮提示词
【目标】做一个周末手冲咖啡体验课的单页介绍站，目的是让感兴趣的人看完就报名。
【受众】25–35 岁城市白领，想学点新东西、周末有事做，最关心课程内容、时间和价格。
【内容】从上到下：
  1. 一句招牌标语 + 一句话说明
  2. 这门课适合谁（三个简短的判断句）
  3. 三节课的内容安排（每节一句话）
  4. 讲师介绍（一段短文）
  5. 时间、地点、价格（清楚易读）
  6. 报名方式与联系方式
【风格】先不定视觉，只做结构。
【技术】单个 index.html 文件，样式写在文件内的 style 标签里，不要后端。
【约束】先不要写任何 CSS，只输出 HTML 结构和占位文案，中文。

验收点：区块顺序对不对？有没有你不需要的块？标语是否有吸引力？文案是否用了真实语气（而不是「这里是副标题」这种占位符）？

确认结构，删掉多余的东西

第一版结构通常会多出一些「看起来应该要有」的块，比如邮箱订阅、合作伙伴 logo。新手页面最大的敌人就是贪多。

第 2 轮提示词
结构基本可以。做三处调整：
1. 删掉「邮箱订阅」那一整块，现在不需要；
2. 把「时间地点价格」移到「讲师介绍」前面，报名的信息越靠前越好；
3. 首屏标语换成：「一个下午，学会自己冲出一杯好咖啡。」
其他块保留，仍然不要写任何样式。

验收点：调整到位且没有顺手改别的地方。如果它多做动作了，直接说「第 3 点以外的部分保持原样」。

给设计规范，让它套样式

把上一章那套设计规范整段贴进去，再加一句「所有值只能引用这些变量」。这一步通常是效果最惊艳的一次修改。

第 3 轮提示词
现在开始写样式，严格遵循下面这套设计规范，不要新造任何色值：

:root {
  --paper:#FBFBF9; --surface:#FFFFFF; --surface-2:#F4F3EF;
  --ink:#0C0C0B;   --ink-2:#46453F;   --ink-3:#78776F;
  --line:#E7E6E0;
  --s1:8px; --s2:16px; --s3:24px; --s4:32px; --s5:48px; --s6:64px; --s7:96px;
  --r-s:10px; --r-m:16px; --r-l:24px;
}

具体要求：
1. 整站只用黑白灰，不出现任何彩色；
2. 首屏标题 font-size: clamp(2.5rem, 6vw, 4.4rem)，字重 600，
   letter-spacing: -0.035em，行高 1.06；正文字号 16px、行高 1.8；
3. 每个区块之间垂直间距 96px，区块之间用 1px 的 --line 横线分隔；
4. 不用大面积阴影，需要层次的块用 1px 边框；
5. 全站统一左对齐，只有首屏标语可以居中。

它大概会给你这样的结构：

关键样式示意
.hero {
  padding: 128px 24px 96px;
  border-bottom: 1px solid var(--line);
  max-width: 1200px;
  margin: 0 auto;
}
.hero h1 {
  font-size: clamp(2.5rem, 6vw, 4.4rem);
  font-weight: 600;
  letter-spacing: -0.035em;
  line-height: 1.06;
  max-width: 18ch;        /* 标题一行别超过 18 个字 */
  margin: 0;
}
.section {
  padding: 96px 24px;
  border-bottom: 1px solid var(--line);
}
.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
.card {
  background: var(--surface);
  border: 1px solid var(--line);
  border-radius: var(--r-m);
  padding: 32px;
}

验收点：是否出现了彩色？区块之间是否够空？标题是否够大？——如果「像文档不像作品」，八成是间距不够，直接说「所有区块间距从 64 提到 96」。

手机端适配

这一步一定要做，而且一定要真的用手机打开看。只让 Agent「检查一下响应式」，它会敷衍你。

第 4 轮提示词
现在处理手机端（宽度 375px 到 720px）：
1. 三列卡片改成单列，间距 16px；
2. 首屏上下内边距减半，标题字号用 clamp 自适应；
3. 所有左右内边距统一 16px，不要出现横向滚动条；
4. 检查长英文单词和链接会不会溢出容器，会的话加 word-break。

改完告诉我：在 375px 宽度下，页面有没有横向滚动。

验收点：在手机浏览器里把页面缩小到最小，左右滑动一下——如果页面能左右晃动，就是有元素溢出了。

补细节：这些小事决定专业度

结构、样式、适配都对了，最后一轮补上「看起来很舒服但说不出为什么」的部分。

第 5 轮提示词
做最后一轮细节打磨，不要改动布局和配色：
1. 报名按钮加悬停效果：底色不变，轻微上移 1px + 淡阴影，过渡 0.2s 缓动；
2. 所有可点击元素加 transition，时长 0.18–0.22s；
3. 卡片悬停时边框颜色加深一点（--line 到 #D7D6CE）；
4. 给页面加 meta：title、description、viewport、theme-color；
5. 用等宽字体给「时间 / 时长 / 价格」这类数字，让数字对齐更整齐；
6. 尊重用户的减少动效设置：加 @media (prefers-reduced-motion: reduce) 关闭动画。

本地打开，逐条验收

用浏览器打开 index.html，按下面的清单看一遍。发现问题就描述现象，不要描述原因——把判断交给 Agent：

  • 「首屏标题和下面那句话挨太近了，间距加大。」（说现象就够了）
  • 「手机上第二张卡片文字贴到边框了，内边距要加大。」
  • 「第三块的横线和文字距离不一致，统一一下。」

到这一步，你手上已经是一个完整、可用、看起来不廉价的落地页。下一步把它发出去。
