本章要点

一份能直接套用的需求模板：目标、受众、内容、风格、技术、约束六个要素。缺一个，Agent 就得靠猜；猜错了，你就要重来一遍。

一、六要素需求模板

把下面这段复制下来，填空，就是一份及格线以上的需求描述。第一次用会有点慢，第三次开始你会发现它能用在几乎所有事情上。

需求模板.txt
【目标】我要做一个 ______ 的网站，主要目的是 ______。
【受众】访问者主要是 ______，他们最关心 ______。
【内容】页面从上到下包含这几块：
        1. ______
        2. ______
        3. ______
【风格】参考 ______（网站/图片），我想要的感觉是 ______，
        特别注意 ______（例如：留白多、标题很大、颜色很克制）。
【技术】单个 HTML 文件，样式写在文件内部，
        不需要后端和数据库，桌面和手机都要正常显示。
【约束】不要 ______（例如：不要花哨渐变动画、不要圆角过大、
        不要用 emoji 当图标）；文案用中文，语气 ______。

六个要素里，【目标】和【风格】是新手最容易省掉、也最不该省的两项。前者决定内容取舍，后者决定视觉方向。

二、差提示词 vs 好提示词，逐句对比

✕ 差 · 常见新手写法

帮我做一个咖啡店的网站，要好看一点的，高级感。

Agent 需要自己猜：是单页还是多页？放菜单还是放故事？「高级感」是酷黑还是奶油白？——每一项都可能猜错。

✓ 好 · 六要素写法

帮我做一个独立咖啡馆的单页介绍网站，目的是让附近的人愿意来店里坐坐。

访问者是 25–35 岁的城市白领，他们最关心营业时间、位置和店里的氛围。

页面从上到下：一句招牌标语、三张氛围图区域、菜单价格表、门店地址与营业时间、一行联系方式。

风格参考一家我很喜欢的极简杂志站，我想要的感觉是干净、暖、留白多、标题大而细。

单个 HTML 文件，样式写在里面，不要后端，手机和电脑都要正常显示。

不要花哨动画，不要 emoji 图标，文案中文、语气温和。

效果差别有多大？差写法通常要来回改 5–8 轮才勉强能看；好写法基本第一版就可用，后面只是微调。

三、怎么描述「风格」——最难也最有价值的一项

「高级」「简约」「有质感」这类词，对 Agent 来说信息量极低。真正有效的方式是用参考物 + 可验证的特征：

模糊说法 可执行的替代写法
简约 只用黑白灰三种颜色，一个页面最多一个强调色
高级 标题字号比正文大 3 倍以上，区块之间留白至少 96px，不要阴影
有科技感 深色背景、等宽字体用于标签、细线条分割、圆形按钮
温暖亲和 米白底色、圆角 16px、正文行高 1.8、避免纯黑文字
活泼 高饱和撞色、倾斜元素、圆润大字号、卡片轻微旋转

如果你有喜欢的网站，直接把网址给 Agent，并说明你喜欢它的哪一点：

风格描述示例.txt
参考 https://example.com 的感觉，具体喜欢三点：
1. 首屏标题特别大，几乎占满一行，字重不重但很有气势；
2. 区块之间用很细的浅灰线分隔，不用卡片阴影；
3. 小标签用等宽字体大写字母，显得很克制。

我们的内容换成 ______，其他保持这种气质。
提示

不要照抄参考站的内容，只抄它的规则（字号关系、留白尺度、色彩克制程度）。抄规则会得到自己的风格，抄内容只会得到一张似是而非的仿制品。

四、迭代时怎么说——「改哪里、别动哪里」

第一版出来之后，才是提示词真正的战场。两个原则：

1. 一次只说一件事

不要说「整体调整一下，感觉哪里都不太对」。要拆成具体的句子：

  • 「首屏副标题和标题挨得太近，间距加大到标题高度的三分之一。」
  • 「卡片的圆角太大了，改成 12px 左右，边框颜色再淡一点。」
  • 「第三块和第四块交换顺序，其他都不要动。」

2. 每次都加一句「不要动其他部分」

Agent 在修改时容易顺手「优化」你没提的地方，结果你好不容易满意的部分被改掉了。明确边界：

修改话术.txt
只修改 ______ 这一处：把 ______ 改成 ______。
其他部分（尤其是 ______）保持原样，不要重构、不要顺手优化。
改完只告诉我改了哪几行。

五、让它反过来问你

最省事的一招：在需求末尾加一句「信息不足的地方先问我，不要猜」。Agent 会列出一串问题，你回答完再动手——比它猜错三轮快得多。

主动提问话术.txt
先别写代码。读完上面的需求后，列出你不确定的信息，
最多问 5 个问题，我回答完你再动手。

六、出手前的 60 秒自检

  • 目标：我写清楚这个网站是给谁、为什么而做了吗？
  • 内容：区块顺序我确认过吗？有没有「先放上去再说」的凑数块？
  • 风格：我给的是可验证的特征，还是「高级一点」这种形容词？
  • 技术：单文件还是多文件？要不要后端？手机端要不要管？
  • 约束：我知道自己讨厌什么吗（颜色、圆角、动效、语气）？
  • 验收：第一版出来后，我打算先看哪一部分？
