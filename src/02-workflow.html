Three Elements

一条提示词，说清三件事

不用背模板，记住 A、B、C 三句就够用。

A / GOAL
目标

这个页面是干嘛的。

例：「咖啡店的课程报名落地页」

B / AUDIENCE
受众

谁会来看。

例：「25–35 岁想学手冲的城市白领」

C / STYLE
风格

像什么，或直接贴一个参考链接。

例：「极简黑白、大字标题，像 Apple 官网」

Prompt Template

拿走就能用的提示词模板

把方括号里的内容换成你的，点右上角复制，粘给任何 Agent。

PROMPT · 四句话
我想做一个[目标：咖啡课程报名落地页]。 受众是[受众：25–35 岁想学手冲的城市白领]。 风格[风格：极简黑白、大字标题、留白多，像 Apple 官网]。 结构：顶部一句话主张 + 三个课程亮点 + 底部报名表单。

把这四句粘给 Agent，就已经超过 80% 的新手提示词了。
