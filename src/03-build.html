介绍 GitHub

上线只用到两个概念，各一句话就够。

GitHub

一个存代码和文件的网站，全球程序员都在用——本教程用它免费上线网页。

GitHub Pages

GitHub 附赠的免费托管服务——把你的 index.html 放进去，就得到一个任何人都能访问的网址。

Go Live

上线五步勾选清单

做完一步勾一步，勾满 5 步就有网址。

✓ 在 github.com 注册账号（如果还没有）。
✓ 右上角「+」→「New repository」，名字随便起，Public，不勾任何初始化。
✓ 按提示在本地 my-site 文件夹里运行三条 git 命令（页面自带复制按钮）。
✓ 回到仓库 → Settings → 左侧 Pages → Source 选 main 分支根目录 → Save。
✓ 稍等片刻，页面顶部出现 https://你的用户名.github.io/仓库名/，发给任何人即可。

Troubleshooting

新手最常踩的四个坑

对着症状找原因，一句解法就能救你两小时。

坑 01
双击打开全是源代码
原因文件存成了 .txt（Windows 默认隐藏扩展名）
解法手动把文件名改成 index.html 再打开
坑 02
页面里的图片全打不开
原因对话型 Agent 经常编造图片地址
解法图片先存到本地，src 改成相对路径（如 images/coffee.jpg）
坑 03
改了文件但页面没变化
原因浏览器缓存；GitHub Pages 重新部署也需要等一会儿
解法按 Ctrl + F5 强制刷新，线上改动稍等再看
坑 04
一次提太多需求，Agent 改崩了
原因改动累计越多，Agent 越容易丢上下文
解法每次只说一件事，改完满意再提下一条
