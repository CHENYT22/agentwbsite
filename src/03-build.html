最短路径

三步，做出你的第一个页面。

照着做一遍，10 分钟内能看到自己的网站在浏览器里打开。

第 1 步 · 把需求发给 Agent

把第 2 章的三要素直接发给任何对话型 Agent。例：

示例提示词

我想要一个咖啡课程报名落地页。受众是 25–35 岁想学手冲的城市白领。风格极简黑白、大字标题、像 Apple 官网那样留白多。单页，顶部一句话主张 + 三个课程亮点 + 底部报名表单。

第 2 步 · 把 Agent 给的代码存成本地文件

在桌面新建一个文件夹，比如 my-site。在文件夹里新建一个文本文件，把 Agent 给的代码粘进去，保存为 index.html。注意文件名后缀必须是 .html。

第 3 步 · 双击打开看效果

直接双击 index.html，浏览器里就出现了你的页面。不满意？回到 Agent 对话框：「把标题再大一点，标题改为『用一杯咖啡，慢下来』，配色换成奶咖色」。改完再覆盖保存，再双击——这就是迭代。

到这里你就掌握了 Agent 建站的核心循环：写需求 → 看效果 → 改需求。剩下的只是熟练度问题。
