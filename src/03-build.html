Step By Step

三步，做出第一个页面

左边是你做的，右边是 Agent 做的。照着走一遍。

STEP 1 把需求发给 Agent
你要做的

打开任意对话窗口，把第 2 章的四句话提示词发给它。下方有现成模板，可直接复制。

Agent 做的

拆解需求，一轮生成完整的 HTML + CSS 代码。

STEP 2 把代码存成本地文件
你要做的

桌面新建文件夹 my-site，新建文本文件，粘贴代码，保存为 index.html。

Agent 做的

待命。你随时可以把报错或疑问丢回给它。

STEP 3 双击打开看效果
你要做的

双击 index.html，页面就在浏览器里了。不满意就回去说一句，改完覆盖保存再看。

Agent 做的

按你的新要求改代码，比如「标题再大一点，配色换成奶咖色」。

⚠️ 最常见的坑：文件名后缀必须是 .html。Windows 默认隐藏扩展名，小心存成了「index.html.txt」。
Example Prompt

第 1 步的示例提示词

不想自己写？直接复制这条发给 Agent，先把流程跑通。

PROMPT · 咖啡课落地页
我想要一个咖啡课程报名落地页。受众是 25–35 岁想学手冲的城市白领。风格极简黑白、大字标题、像 Apple 官网那样留白多。单页，顶部一句话主张 + 三个课程亮点 + 底部报名表单。

到这里你就掌握了核心循环：写需求 → 看效果 → 改需求。剩下的只是熟练度。
