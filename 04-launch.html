第 04 章 · Beginner's Guide

发布到公网 + 新手四个坑

GitHub Pages 一键部署；四条经验省你两小时踩坑时间。

预估阅读 2 分钟 难度：新手友好
发布

五句话上线。

  1. 在 github.com 注册账号（如果还没）。

  2. 右上角「+」→「New repository」，名字随便起，Public，不要勾任何初始化。

  3. 按提示在本地 my-site 文件夹里运行三条 git 命令（页面会直接给你复制按钮）。

  4. 回到仓库 → Settings → 左侧 Pages → Source 选 main 分支根目录 → Save。

  5. 等一分钟，页面顶部会出现一个 https://你的用户名.github.io/仓库名/ 链接，发给任何人即可。

新手最常踩的四个坑

01

文件名存成了 .txt

Windows 默认隐藏扩展名，「index.html.txt」在浏览器里打开就是源代码。保存时手动写 index.html。

02

Agent 给的图片链接打不开

对话型 Agent 经常编造图片地址。把图先存到本地，把 src 换成相对路径（如 images/coffee.jpg）。

03

改了文件但页面没变化

浏览器按 Ctrl + F5 强制刷新。GitHub Pages 也需要 1–3 分钟重新部署。

04

一次提太多需求，Agent 改崩了

每次只说一件事，改完不满意才追加下一条。改动累计越多，Agent 越容易丢上下文。

到这里就真的做完了。剩下的就是反复迭代——而那正是 Agent 最擅长的事。
